# DNTT preprocessing regression data

These are BSD-3-Clause PyEPH test data from
`https://github.com/jiangtong1000/PyEPH`, revision
`6c4693acbb69a06a5bc8b0593abde2170ff38843`,
`pyeph/post_qe2pert/test`. The original repository describes this as its
small DNTT q222/k222 fixture. It has 72 atoms and two Wannier orbitals.

`DNTT_epr.h5` is an unchanged 4,173,800-byte copy. `references.h5` contains
only the numerical reference entries used here; it is not generated by the
migrated implementation. `provenance.json` records the original files' SHA256
hashes, the source revision, and the selected reference indices.

The electronic and phonon references retain path indices 0, 37, 200 and 510
from the 511-point path in the original tests. Phonon frequencies are in Ry.
The EPC reference is the first q and first k entry from `DNTT_ephmat.h5`;
the original test defines their path indices by `RandomState(0)` drawing ten
q indices followed by ten k indices without replacement. Both explicit
coordinates are saved in the reduced reference file. The EPC quantities use
the original test's output units (eV/Angstrom and meV).

The original calculations that produced these saved references were not
rerun with external QE/PERTURBO executables during migration. Matching them
establishes regression parity for the tested entries, not independent
physical validation of the original calculation or a full-grid error bound.
